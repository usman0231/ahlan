AHLAN HSE - TESTING SETUP (Windows)
===================================

1) YEH 3 CHEEZEIN INSTALL KAREIN (eik dafa)
   - Node.js 22 LTS ........ https://nodejs.org
   - Docker Desktop ........ https://www.docker.com/products/docker-desktop
                             (install ke baad Docker Desktop khol kar chalta chhor dein)
   - pnpm .................. Terminal (Command Prompt) mein:  npm install -g pnpm@9.15.9


2) PEHLI DAFA SETUP (project folder mein terminal khol kar, eik eik line chalayein)

   pnpm install
   docker compose up -d
   copy apps\api\.env.example apps\api\.env
   copy apps\mobile\.env.example apps\mobile\.env
   pnpm --filter @ahlan/shared build
   pnpm --filter api prisma:generate
   pnpm --filter api prisma:deploy
   pnpm --filter api db:seed
   pnpm --filter api browsers:install

   Phir "apps\mobile\.env" ko Notepad mein kholein aur yeh line aise kar dein:
   EXPO_PUBLIC_API_URL=http://localhost:3000


3) APP CHALAYEIN (har dafa)
   Docker Desktop on ho. Phir DO terminal kholein:

   Terminal 1:   pnpm --filter api dev
   Terminal 2:   pnpm --filter mobile web

   Browser mein kholein:  http://localhost:8081
   (Pehli dafa load hone mein 1-2 minute lag sakte hain.)
